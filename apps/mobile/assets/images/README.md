# Images

`world-equirectangular.png`, `star-outline.png` and `star-solid.png` are drawn by
shared components, so they live in `packages/ui/assets/images/`; the scripts
below write them there. Everything else stays here.

## `world-equirectangular.png`

A land mask in equirectangular projection, covering the whole globe exactly:
longitude −180 to 180 across the width, latitude 90 to −90 down the height. So

    x = (lon + 180) / 360 × width
    y = (90 − lat) / 180 × height

is the entire transform, with no crop or inset to correct for. 1440 × 720.

Rasterised from **Natural Earth** `ne_110m_land` (public domain, no attribution
required, naturalearthdata.com) by `scripts/build-world-map.ts`. Grayscale with
alpha, land opaque and sea transparent, so it is tinted at render time and works
in either theme.

Used by the onboarding place card. Nothing on Today draws a map; the spec keeps
the home screen undecorated.

## The brand assets

`icon.png`, `adaptive-icon.png`, `adaptive-icon-mono.png`, `splash-icon.png`,
`notification-icon.png`, `star-outline.png`, `star-solid.png` and the small
`packages/ui/assets/images/app-icon.png` (the icon as the widget gallery's header
and onboarding's notification pictures draw it) are generated by
`scripts/build-brand-assets.ts`. Run it
with `bun scripts/build-brand-assets.ts`, or add `--variants <dir>` to write
comparison sheets somewhere scratch without touching this folder.

They draw the eight-point star from `packages/ui/src/components/onboarding-art.tsx` — two
squares, one turned 45° — in the palette hexes from `src/theme/colors.ts`, so
the icon and the app cannot drift apart. The outline treatment was chosen over
a solid star and a reversed one.

`icon.png` is written without an alpha channel, because iOS rejects an icon with
transparent pixels; the rest keep one so Android can mask them. The notification
glyph is solid rather than outlined: at status-bar size a hairline disappears.

`star-outline.png` and `star-solid.png` are the stamps `OnboardingArt` draws,
white so `tintColor` can paint them from the palette. They exist because the
motif is a union of two squares, and composing it from two `View`s on screen
shows the crossing lines through an outline and a darker patch where the squares
overlap when shaded. Drawing from the same generator as the icon means the mark
on screen and the mark on the home screen cannot drift apart.

`app-icon.png` (in `packages/ui/assets/images/`, 180 × 180, no alpha) is `icon.png`
drawn small, for screens that show the app icon as the system does: the widget
gallery's header and the app name under each widget preview. A screen in
`@ihsaanly/ui` cannot reach this folder, so the generator writes it there.
