# Images

- `world-equirectangular.png` — land silhouette, equirectangular projection,
  cropped to the projection so x = (lon + 180) / 360 and y = (90 − lat) / 180.
  Derived from Wikimedia Commons "BlankMap-World-Equirectangular.svg", public
  domain. Grayscale with alpha so it can be tinted at render time. Used by the
  onboarding place card; nothing on Today draws a map.
